# Projektregeln

## Verwendete Technik
- Verwende Vite, Tailwind CSS v4 und Vanilla JavaScript.
- Füge keine Frameworks oder Pakete hinzu, ohne vorher zu fragen.

## Änderungen
- Orientiere dich am vorhandenen Aufbau und ändere nur, was für die Aufgabe nötig ist.

## Befehle
- Entwicklung starten: `npm run dev`
- Projekt bauen und prüfen: `npm run build`
- Den Build lokal ansehen: `npm run preview`
- Führe nach Änderungen `npm run build` aus und melde Fehler offen.
