# Tasks – MeinFriseur Demoseite

## Arbeitsweise
Ein Schritt nach dem anderen, in der Reihenfolge unten. Nach jedem Schritt `npm run build`, kurze Prüfung, dann abhaken. Design siehe `disign.md`.

## Ziel
Demo-Seite für potenzielle Kunden. Sie soll zur Kontaktaufnahme anregen, schnell und performant laden und trotz Demo alle relevanten Metadaten enthalten. Es gibt keine Logos und Bilder, überall werden Platzhalter verwendet.

## Grunddaten
- Salonname: MeinFriseur
- Hauptziel: Telefonanruf
- Indexierung: `noindex` (nur Demo)
- Stack: Vite, Tailwind CSS v4, Vanilla JS (siehe `AGENTS.md`)
